How It Works

🎬

Video Processing

Extract audio, transcribe with Whisper, sample keyframes using SSIM, and detect objects/faces with YOLO and CLIP.

🔬

Frame Classification

Hybrid ResNet50 + CLIP model classifies frames into equations, diagrams, code, charts, and more with high accuracy.

🧠

Text Summarization

BART generates initial summaries refined by Mistral-7B LLM for high-quality, context-aware lecture notes.

📄

Document Generation

CLIP+BART fusion creates multimodal summaries exported as PDF, Markdown, and interactive HTML documents.
